# DevOps Responsibilities

Typical responsibilities for this platform include:

- GCP infrastructure administration
- Cloud Run deployments
- Cloud SQL operations
- Load balancer management
- WAF/security configuration
- Cloud Storage administration
- VM administration
- Grafana dashboards and observability
- Zabbix infrastructure monitoring
- Telegram alerting
- Incident troubleshooting
- Staging and production release management
- Backup and recovery coordination
- Security and access management
