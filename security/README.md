# Security

## Security Controls

The platform uses:

- WAF protection
- HTTPS external load balancing
- IAM-based access control
- Cloud Run service isolation
- Cloud SQL database separation between environments
- Monitoring and alerting
- Zabbix infrastructure monitoring
- Grafana observability
- Telegram notifications

## Public Repository Policy

Do not publish:

- Credentials
- Service account keys
- API keys
- Database passwords
- Telegram bot tokens
- Internal IP addresses
- Public IP addresses
- Production secrets
- Private certificates
- Sensitive firewall configuration
